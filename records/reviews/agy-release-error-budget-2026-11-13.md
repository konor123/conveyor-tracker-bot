- 작성: Antigravity(Claude Opus 5.5) worker, 읽기 전용 분석. 저장소 파일 수정 없음. 실행 장소 GCE(순수 계산, 로봇·PC 접속 없음).

## 2. 합성 추정

규칙: 서로 독립인 성분의 XY 반경 p95를 RSS로 합친다(= 등방 정규에서 1σ RSS × 2.45). 미측정 C6 편향·C8·C10은 0으로 두었으므로 **하한 성격**이다. 참고로 선형 합(최악)도 적는다. 공통 항 C1 1.35, C2 0.53, C5 0.903(원시), C7 0.5, C9 0.34 → 공통 RSS √(1.8225+0.2809+0.8154+0.25+0.1156) = √3.284 = **1.81 mm**. C4에 남는 여유 = √(3.25² − 3.284) = √7.278 = **2.70 mm**.

**MODE_SYNCHRONIZED**(C4 = H 0.1 s 값):

| 조건 | C4 | RSS | 선형 합 | 몫(분산 비) C1 / C2 / C4 / C5 / C7 / C9 |
|---|---:|---:|---:|---|
| fast-1-long(53 mm/s, 최소) | 2.15 | √(3.284+4.623) = **2.81** | 5.77 | 23 / 4 / 58 / 10 / 3 / 1 % |
| stable(24~31 mm/s) | 2.41 | √(3.284+5.808) = **3.02** | 6.03 | 20 / 3 / 64 / 9 / 3 / 1 % |
| fast-1(54 mm/s) | 2.57 | √(3.284+6.605) = **3.14** | 6.19 | 18 / 3 / 67 / 8 / 3 / 1 % |
| fast-2(82 mm/s) | 2.64 | **3.20** | 6.26 | 18 / 3 / 68 / 8 / 2 / 1 % |
| maximum(127 mm/s) | 3.57 | √(3.284+12.745) = **4.00** | 7.19 | 11 / 2 / 80 / 5 / 2 / 1 % |

- C5를 시차 보정값 0.062로 두면 최소 조건 RSS 2.66 mm. 보정 C1을 0.5 mm로 줄여도 fast-1 RSS는 3.14 → 2.88 mm, 2.0 mm(1점 상한)이면 3.47 mm다.
- 판정: 저·중속(≤ 82 mm/s)에서 측정된 성분만으로 2.8~3.2 mm, 여유 0.05~0.45 mm. 미측정 C8·C6 편향이 0.5~1 mm만 되어도 넘는다. 127 mm/s는 측정 성분만으로 넘는다.

**MODE_PREDICTED**(C4 = H ≥ 1.3 s, 1.3 s 값이 없어 1 s 값을 하한으로 사용):

| 조건·H | C4 | RSS | 몫 C4 |
|---|---:|---:|---:|
| fast-2, 1 s | 5.33 | **5.63** | 90 % |
| fast-1, 1 s | 6.86 | √(3.284+47.06) = **7.10** | 93 % |
| stable, 1 s | 13.41 | **13.53** | 98 % |
| fast-1, 2 s / 3 s | 10.82 / 20.15 | **10.97 / 20.23** | 97 / 99 % |

- 예측 모드가 3.25 mm 안에 들려면 C4 ≤ 2.70 mm, 즉 H ≈ 0.1 s 이하여야 한다. 현 벨트 맥동에서는 H ≥ 1.3 s 설계로 성립하지 않는다(G4 기준 "예측 오차 p95 ≤ 1.5 mm"도 같은 이유로 어렵다).
- 해제 게이트 `position_std_max` 0.5 mm와 보고 std(0.1 s 0.26, 0.5 s 0.61, 1 s 1.08 mm)를 맞대면, 게이트가 고정 계획으로 판정되는 한 H > 약 0.4 s인 예측 모드 해제는 `GATE_POSITION_STD`로 막힌다(구현에서 예측 모드 게이트가 어떤 revision을 쓰는지 확인 필요).

## 3. 지배 성분과 미지 성분

- **지배**: C4 단기 예측(동기 58~80 %, 예측 90~99 %). 원인은 벨트 속도 맥동(검출 잡음은 0.1~0.3 mm로 작음). 다음이 C1 보정(11~23 %), C5 추종(5~10 %, 원시값 기준).
- **작음**: C2 평면 높이(2~4 %), C9 낙하(≤ 1 %), C3 검출 잡음(C4에 포함).
- **미지(예산을 뒤집을 수 있음)**: C8 파지 오프셋, C7 실제 개방 지연과 개방 중 추종 교란, C6 카메라 stamp 편향·drift(54 mm/s에서 10 ms당 0.54 mm), vision 실제 처리 시간(H를 늘림), C10 진행 방향, G5 벨트 동기 추종 오차, 생산 vision 부하에서의 스트림 지연.
- C4 값 자체가 압축 영상·후보 보정·독립 GT 없음 자료다. maximum 0.05 s 오차가 한 프레임 이동량에 가까워 프레임 시각 지터 가능성이 있다(README). 원본 bag으로 다시 재면 바뀔 수 있다.

## 5. 한계

- C4는 압축 영상·후보 보정·다이얼 고정·단일 조명 자료이며 미래 검출 잡음이 섞인 "H초 뒤 검출 대비" 오차다(독립 GT 아님).
- C1은 재투영 잔차의 mm 환산(표식 깊이 0.39~0.45 m 기준)으로, 작업면(테두리 높이, 카메라에서 약 0.50 m)과 깊이가 다르고 체계 오차를 담지 못한다. 물리 검증 0점.
- C2의 tanθ는 정지 투입 뚜껑 한 위치 기준이다. 시야 가장자리에서는 더 크다.
- RSS는 독립·정규 가정이다. C4는 꼬리가 두껍고(0.1 s p50 0.45~0.97 mm 대비 p95 2.15~3.57 mm) C1은 편향이라 실제 p95는 RSS보다 클 수 있다. 미측정 성분을 0으로 둔 하한이다.
- 예측 모드 H(계획 고정 시점)는 구현 확인 전 가정이다(1.3~2.8 s, `specs/SPEC-500` `entry_lead_s`, README 해석 절). 1.3 s 값이 없어 1 s 값을 썼다.
- 동적 해제 높이와 낙하 높이는 TBD(OFF-6)이며 C9는 상한 가정이다.
