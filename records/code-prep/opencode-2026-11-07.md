# robot_control 코드 준비 기록 (2026-11-07)

작성: OpenCode worker. 범위는 `src/robot_control/**`와 `specs/SPEC-500-robot-control.md`다. 실기·그리퍼·카메라·`/dsr01` 연결과 지령은 수행하지 않았다.

## 구현 범위

- `motion_adapter.py`: SI↔Doosan(mm/deg, ZYZ) 변환, 속도 변환, freshness 래치, 작업영역·속도 검사, 단일 지령 권한, 추종 지령식.
- `gripper_adapter.py`: pulse 표 검증, protocol별 주소표, Modbus CRC/FC03·FC06·FC16, 7비트 코덱·트리거, 시작 확인, Goal Current→Goal Position 순서, 부분 개방, 시간·오류 비트·루프 생존, 정지 확인.
- `skill_logic.py`: MoveToPose·PickStone·PlaceStone·SafeRetreat·Stop의 순수 Python 판단. 성공은 backend 측정값 기준. 설정 누락·lifecycle 비활성·backend disabled·동시 goal은 `PRECONDITION`. DynamicPlace는 `PLANNER_NOT_READY`로 닫음.
- `fake_backend.py`: `backend:=fake`에서만 쓰는 시뮬레이션 backend. 값은 하드웨어 측정이 아니다.
- `robot_controller_node.py`: lifecycle, 5개 action, Stop service, RobotStatus·Heartbeat 10 Hz, 동시 goal 거부, cancel·deadline, inactive 거부. 기본 backend `disabled`.
- `config/robot_control.yaml`: `backend: disabled`만 둔다. 기하·폭·전류 임계는 실측 전까지 넣지 않는다.
- `setup.py`·`package.xml`: 노드 entry point와 ROS 의존성.

## 시험 표시

추가 시험은 `req`·`tc`·`level` 마커와 기존 `conftest.py` 공통 plugin을 쓴다. 다룬 TC는 ROB-001~010, GRP-001~010·011~013의 단위 항목이다. `[ON]` 실기 항목은 수행하지 않았다.

## 남은 구현·시험

- 실제 Doosan stream·move_line transport와 그리퍼 transport를 노드 backend에 연결하지 않았다. 현재 노드는 `disabled`/`fake`만 지원한다.
- DynamicPlace 계획기·추종 제어, plan revision·epoch·만료 처리는 미구현이다.
- SafeRetreat `keep_sync=true`와 `place_back=true`는 `PRECONDITION`이다.
- 그리퍼 상주 루프 DRL·생존 카운터와 실기 register 읽기/쓰기는 미수행이다.
- `tools/testing/contracts/robot_controller_contract.py` 전체 계약은 DynamicPlace 성공과 실기 backend를 전제하므로 통과하지 않는다. fake 노드 smoke로 대체 확인했다.
- TDD 기록: 시험과 구현을 같은 작업에서 작성했고, 구현 전 실패 상태를 별도로 캡처하지 못했다. 현재 선택 범위 시험은 모두 통과한다.
