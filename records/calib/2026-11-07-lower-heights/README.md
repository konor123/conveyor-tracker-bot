# 낮은 카메라 높이 촬영 자료 보관

원본은 바이트 그대로 복사했고 원래 경로의 파일도 유지했다. 출처·실제캡처로그·파일시각·SHA-256은 `provenance.json`, 이미지목록은 `image-index.csv`, 전체무결성목록은 `SHA256SUMS`다.

- `initial-height/`: 초기 ChArUco 카메라 촬영과 파생 표시영상. 초기 설치 높이350mm는 사용자 제공 공칭값(L01)이며 각 영상의 정확한 높이를 별도로 실측한 기록은 없다. `drop_data`와 임시작업폴더에서 회수했다. 원래 파일명이 다른 동일바이트 사본도 출처별로 보존했다.
- `before-450mm/`: 회전 전후 및 상대이동 후 원본3장. 450mm로 높이기 전 촬영됐지만 영상별 정확한 높이는 미확정이다.
- `height-450mm/`: 사용자 제공450mm 높이 확인 원본·표시영상·검출JSON.
- `board-reference-renders/`: 보정표적 인쇄물PDF의 렌더2장. 카메라로 촬영한 영상과 구분한다.
- `takeover-source-metadata/`: 해당 세션의 원래 촬영·일부 팔자세 기록. 존재하지 않는 영상별 팔자세나 외부변환은 만들지 않았다.

이미지파일 25개, 그중 카메라원본 사본 14개(SHA-256으로 구분한 고유 촬영 11장)를 보존했다. 나머지는 표시·확대·인쇄참고영상이다. 600mm 최종 Hand-Eye 세션은 `../2026-11-07-final-layout/`에 보관돼 있으며 이 낮은높이 자료를 그 세션의 대응점으로 섞지 않는다.
