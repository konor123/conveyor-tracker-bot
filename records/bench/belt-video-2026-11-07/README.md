# 2026-11-07 벨트 영상 병뚜껑 추적 재생

OFF-1 이동 벨트 RGB 영상 5개(`records/media/2026-11-07/`, H.264 재생용 복사본)에 생산 검출기(`vision.pipeline`)를 돌려 병뚜껑 검출을 뽑고, 실제 `TrackManager`와 planner `predict`로 재생했다. 원본 rosbag이 아니라 압축 영상이며 시각은 `.frames.csv`의 원래 header stamp다.

## 재현

```bash
~/.venvs/vision/bin/python tools/eval/extract_cap_detections.py records/media/2026-11-07/*moving*.rgb.mp4 \
    --out-dir records/bench/belt-video-2026-11-07          # OpenCV 필요, GCE 2코어에서 영상당 약 13분
python3 tools/eval/replay_belt_tracking.py records/bench/belt-video-2026-11-07/*.caps.csv \
    --sigma-accel 0.1 --json records/bench/belt-video-2026-11-07/replay-sigma-0.1.json
```

- 보정: 외부 변환 `cal-2026-11-07-handeye-01` 후보값(hand-eye 18:52~19:31 촬영, 영상 20:06~20:22, 그 사이 카메라 유지) + 2026-11-09 잠정 벨트 평면(매트 + 93 mm). 독립 접촉 검증 0점인 후보 보정이므로 mm 값은 잠정값이다.
- `conveyor_frame`은 보정 전이라 검출 XY의 주성분을 진행 방향으로 둔 임시 좌표계다. robot_base 기준 진행 방향은 거의 +y다.
- 예측 오차는 독립 GT가 아니라 "H초 뒤 실제 검출 위치" 대비이며 검출 잡음을 포함한다. 같은 뚜껑 판정 반경 40 mm.

## 해석

- 해제 허용 오차 초기값 `e_xy_max` 2.75 mm(SPEC-100) 기준으로, 등속 예측이 이 값을 지키는 horizon은 stable에서 약 0.2 s, fast-1·fast-2에서 0.1 s 안팎이다. MODE_PREDICTED가 가정한 약 2.8 s 앞 예측(`t_transit + t_sync + t_descend`)은 모든 조건에서 20 mm 이상 벗어난다.
- 그리퍼가 뚜껑을 가리는 동안(τ) 등속 예측만 믿으면 0.1~0.2 s 안에 허용 오차를 넘는다. 해제 직전까지 뚜껑 또는 벨트 표식(Progress 7절 선택 항목)을 계속 관측해야 한다.
- 시간 예산 `T_required` 4.0 s + margin 1.0 s는 관측 구간 체류 시간 기준으로 약 55 mm/s 이하에서만 성립한다. 실제 사용 구간은 관측 구간과 로봇 도달 구간의 교집합이라 더 짧다.
- 이 자료는 단일 조명·압축 영상·후보 보정이다. G3 실측(독립 GT) 판정이나 파라미터 확정에 쓰지 않는다.
